# Legacy Guest App Versions

This directory contains archived versions of VirtualBuddyGuest referenced by the software catalog.

In current VirtualBuddy releases, legacy guest apps only support automatic mounting of shared folders on macOS 13 or later. Clipboard sharing requires the latest guest app. VirtualBuddyGuest is not supported on macOS 12 or earlier.

The macOS 12 catalog entry is retained to recognize existing configurations and for older VirtualBuddy releases. Current releases do not offer it for new selections or attach its installer.
